# Constitución de producto — AquaGest + Pozos

> Principios innegociables. Se escribe una vez por producto; toda spec, plan y tarea los cumple.

**Modo SDD:** actualización — desde 02-oct-2026. Ya existe una demo publicada (spec 001) y esta es la segunda spec
del proyecto; desde aquí cada spec lleva su radio de impacto (`impacto.md`) antes del plan. Es de un solo sentido: no
vuelve a «nuevo».

1. **La spec manda.** Nada se construye sin spec aprobada por el grupo; si falta una decisión, se
   para y se pregunta (o el grupo decide explícitamente delegarla, como en la spec 001).
2. **Nunca se declara potabilidad automáticamente.** El sistema compara cada resultado contra el límite
   verificado del reglamento aplicable — el criterio final es de la revisión técnica humana, no del software.
3. **Toda concentración de nitrato se guarda con su unidad explícita** (NO3⁻ o N-NO3) — nunca un
   número suelto sin decir en qué unidad está.
4. **Nada se borra.** Los datos de ejemplo/prueba se marcan como tales, nunca se presentan como
   datos reales de una comunidad.
5. **Presupuesto: solo herramientas gratis.** GitHub Pages para publicar; ningún servicio de pago
   de ningún integrante del grupo se usa para este proyecto.
6. **Español** en pantallas y mensajes.
7. **Funciona en un celular común** — el técnico llena esto en el campo, no en oficina.
8. **Toda decisión de alcance se anota en la spec**, no se asume en silencio.
9. **Ningún límite normativo se inventa.** Solo se cargan límites verificados contra el texto oficial, indicando de
   qué reglamento salen; todo lo demás se muestra como «Límite no cargado» o «Sin criterio aplicable».
10. **Cumple / No cumple solo después de una revisión técnica humana confirmada.** El sistema compara y propone; no
    declara por sí mismo.
11. **Todo permiso vive en dos lugares:** la pantalla lo oculta y la acción lo vuelve a comprobar (doble candado).
12. **Todo texto que escribe un usuario se escapa antes de mostrarse** y todo archivo se verifica por su contenido, no
    solo por su extensión.

# Constitución de producto — AquaGest + Pozos

> Principios innegociables. Se escribe una vez por producto; toda spec, plan y tarea los cumple.

**Modo SDD:** nuevo — desde 30-sep-2026. Proyecto universitario que arranca, sin usuarios reales
todavía; es una entrega de curso (UTP, Ingeniería Ambiental). Su primera spec (`001`) queda exenta
del radio de impacto; desde la segunda spec, este proyecto pasa a modo actualización.

1. **La spec manda.** Nada se construye sin spec aprobada por el grupo; si falta una decisión, se
   para y se pregunta (o el grupo decide explícitamente delegarla, como en la spec 001).
2. **Nunca se declara potabilidad automáticamente.** El sistema compara contra el Valor Máximo
   Permitido (VMP) y muestra un estado de referencia (verde/amarillo/rojo) — el criterio final es
   del laboratorio y del técnico, no del software.
3. **Toda concentración de nitrato se guarda con su unidad explícita** (NO3⁻ o N-NO3) — nunca un
   número suelto sin decir en qué unidad está.
4. **Nada se borra.** Los datos de ejemplo/prueba se marcan como tales, nunca se presentan como
   datos reales de una comunidad.
5. **Presupuesto: solo herramientas gratis.** GitHub Pages para publicar; ningún servicio de pago
   de ningún integrante del grupo se usa para este proyecto.
6. **Español** en pantallas y mensajes.
7. **Funciona en un celular común** — el técnico llena esto en el campo, no en oficina.
8. **Toda decisión de alcance se anota en la spec**, no se asume en silencio.
